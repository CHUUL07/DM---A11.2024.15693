# Course 2 - Regression

Materi Course 2 mata kuliah Data Mining (A11.2024.15693): regresi linear, transformasi target, regresi polinomial, cross validation, dan regularisasi.

## Struktur

| Modul | Topik | Materi |
| --- | --- | --- |
| Modul - 1 | Linear Regression & Transforming Target | `Linear Regression.ipynb`, `02a_LAB_Transforming_Target.ipynb`, `FinalAssignment.ipynb`, `data/boston_housing_clean.pickle`, `data/CarPrice_Assignment.csv` |
| Modul - 2 | Polynomial Regression | `Polynomial_Regression.ipynb`, `data/encoded_car_data.csv` |
| Modul - 3 | Cross Validation | `02c_DEMO_Cross_Validation.ipynb`, `Cross_Validation.ipynb`, `data/boston_housing_clean.pickle`, `data/encoded_car_data.csv` |
| Modul - 4 | Regularization (Demo) | `02d_DEMO_Regularization.ipynb`, `data/Ames_Housing_Sales.csv`, `data/X_Y_Sinusoid_Data.csv` |
| Modul - 5 | Regularization (Lab) | `02e_LAB_Regularization.ipynb`, `Polynomial_Regression.ipynb`, `data/boston_housing_clean.pickle`, `data/encoded_car_data.csv` |
| Modul - 6 | Final Assignment | `02a_LAB_Transforming_Target.ipynb`, `FinalAssignment.ipynb` |

## Cara Menjalankan

1. Install dependency: `pip install jupyter pandas numpy matplotlib seaborn scikit-learn`
2. Jalankan notebook: `jupyter notebook`
3. Buka notebook sesuai modul. Notebook yang memuat `.pickle`/`.csv` membaca file dari folder `data/` di modulnya masing-masing.
