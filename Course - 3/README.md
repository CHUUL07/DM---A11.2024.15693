# Course 3 - Classification & Ensemble Methods

Materi Course 3 mata kuliah Data Mining (A11.2024.15693): regresi logistik, KNN, decision tree, SVM, imbalanced data, serta ensemble (bagging, boosting, stacking).

## Struktur

| Modul | Topik | Materi |
| --- | --- | --- |
| Modul - 1 | Logistic Regression, KNN, Decision Tree, Bagging | `03a_LAB_Logistic_Regression_Error_Metrics.ipynb`, `03b_LAB_KNN.ipynb`, `03d_LAB_Decision_Trees.ipynb`, `03e_DEMO_Bagging.ipynb`, `lab_jupyter_logistic_regression.ipynb`, `lab_jupyter_knn.ipynb`, `lab_jupyter_decisiontree.ipynb`, `lab_jupyter_svm.ipynb`, `lab_jupyter_imbalanced_data.ipynb`, `Ramdom_forest.ipynb`, `Stackin__For_Classification_with_Python.ipynb` |
| Modul - 2 | Classification (lanjutan) | Sama seperti Modul - 1 |
| Modul - 3 | + Support Vector Machine | Modul - 1 ditambah `03c_DEMO_SVM.ipynb` |
| Modul - 4 | Classification (lanjutan) | Sama seperti Modul - 3 |
| Modul - 5 | Boosting & Stacking | Modul - 3 ditambah `03f_LAB_Boosting_and_Stacking.ipynb`, `Ada_Boost.ipynb`, `Bagging.ipynb`, `Gradient_Boosting.ipynb` |
| Modul - 6 | Model Explanations | Modul - 5 ditambah `lab_jupyter_model-explanations.ipynb` |

Catatan: beberapa file pada Modul - 5 dan Modul - 6 memiliki akhiran `(1)`/`(2)` karena merupakan salinan lanjutan dari modul sebelumnya.

## Cara Menjalankan

1. Install dependency: `pip install jupyter pandas numpy matplotlib seaborn scikit-learn imbalanced-learn xgboost`
2. Jalankan notebook: `jupyter notebook`
3. Buka notebook sesuai modul.
