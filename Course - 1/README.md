# Course 1 - Data Understanding & Preparation

Materi Course 1 mata kuliah Data Mining (A11.2024.15693): pembacaan data, data cleaning, exploratory data analysis (EDA), feature engineering, dan hypothesis testing.

## Struktur

| Modul | Topik | Materi |
| --- | --- | --- |
| Modul - 1 | Reading Data | `01a_DEMO_Reading_Data.ipynb`, `01b_LAB_Reading_Data.ipynb`, `data/baseball.db`, `data/classic_rock.db` |
| Modul - 2 | Data Cleaning | `01a_DEMO_Reading_Data.ipynb`, `01b_LAB_Reading_Data.ipynb`, `Data_Cleaning_Lab.jupyterlite.ipynb`, `Ames_Housing_Data1.tsv` |
| Modul - 3 | EDA & Feature Engineering | `01c_LAB_EDA.ipynb`, `01d_DEMO_Feature_Engineering.ipynb`, `Feature_Engineering_Lab.ipynb`, `Practice Lab Exploratory Data Analysis.ipynb`, `iris_data.csv`, `airlines_data.xlsx` |
| Modul - 4 | Hypothesis Testing | `01c_LAB_EDA.ipynb`, `01e_DEMO_Hypothesis_Testing.ipynb`, `Feature_Engineering_Lab.ipynb`, `HypothesisTesting_Lab.ipynb`, `insurance.csv` |

## Cara Menjalankan

1. Install dependency: `pip install jupyter pandas numpy matplotlib seaborn scipy scikit-learn openpyxl`
2. Jalankan notebook: `jupyter notebook`
3. Buka notebook sesuai modul. Notebook `01b_LAB_Reading_Data.ipynb` pada Modul - 1 membutuhkan file database di folder `data/`.
